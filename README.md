# Harcama Takip Sistemi

## 📌 Proje Açıklaması

Bu proje, kullanıcıların günlük harcamalarını takip edebileceği web tabanlı bir CRUD uygulamasıdır.

## 🚀 Kullanılan Teknolojiler

* Frontend: Vanilla JavaScript (SPA)
* Backend: Node.js, Express
* Database: MySQL
* API: RESTful API
* Documentation: Swagger (OpenAPI)
* Testing: Jest

## ⚙️ Kurulum

```bash
git clone https://github.com/rewakasem13-lab/HarcamaTakipSistemi.git
cd backend
npm install
npm start
```

## 🌐 API Kullanımı

* GET /api/harcamalari-getir
* POST /api/harcama-ekle
* PUT /api/harcama-guncelle/:id
* DELETE /api/harcama-sil/:id

## 📘 Swagger Dokümantasyonu

http://localhost:3000/api-docs
