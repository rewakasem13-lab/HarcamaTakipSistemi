# BudgetFlow - Harcama Takip Sistemi

## 📌 Proje Açıklaması
Bu proje, kullanıcıların harcamalarını yönetmesini sağlayan bir web uygulamasıdır. 
Kullanıcılar harcamalarını ekleyebilir, listeleyebilir, güncelleyebilir ve silebilir.

---

## ⚙️ Kullanılan Teknolojiler
- Node.js
- Express.js
- MySQL (XAMPP)
- Swagger (API Documentation)

---

## 🚀 Özellikler
- Harcama ekleme (POST)
- Harcama listeleme (GET)
- Harcama güncelleme (PUT)
- Harcama silme (DELETE)
